# 瞄一眼 / Hold to Peek v2.0.0

按住看参考，松手接着干。Windows 与 Ubuntu 包在本次 Release 同时提供。

## 中文

### 更新内容

- 默认 F1 快速框选，支持长按去重和占用提示。
- 框选键、按住查看键支持自定义键盘组合；查看支持鼠标中键和前后侧键。
- 参考设置、按键设置、启动与运行、使用说明分为独立页面。
- 可选登录自启与 CPU 高优先级，默认关闭。Windows 自启后留在托盘；关闭高优先级可恢复普通调度。
- 新增 Ubuntu 20.04+ **X11/Xorg 实验版**：框选、按住查看、滚轮高亮、阅读位置、按键录入、托盘与登录自启。
- 采用 MIT 协议，截图只存内存，退出清除。

### 选择下载


### 兼容性与验证范围

**Ubuntu 尚不支持 Wayland，也未完成 Ubuntu 实机或 apt 安装验收。** 需要可用的 X11/Xorg 桌面会话；不要把 XWayland 当成对原生 Wayland 的完整支持。Ubuntu 按住查看期间临时接管键盘与鼠标来隔离滚轮，松手恢复。Linux 可能拒绝提高 CPU 优先级，程序会提示，不请求 root 权限。

Windows Release 构建、57 项核心检查、9 组设置检查、46 项离屏布局及运行偏好断言通过。Linux 16 项纯逻辑、X11 事件模拟、Python 3.8 语法和包结构检查通过；静态检查通过。实际桌面侧键、焦点、DPI、锁屏/休眠和多屏行为仍需验证。Windows 程序未代码签名；构建保留原有 WFO0003 DPI 警告。README GIF 是交互示意，部分界面展示基于 1.0.0。

## English

Windows and Ubuntu packages are available together in this release.

### What's new

- F1 quick capture with repeat suppression and shortcut conflict feedback.
- Record custom keyboard chords for capture and hold-to-peek; peek also supports middle and side mouse buttons.
- Separate pages for reference settings, shortcuts, startup/runtime preferences, and the guide.
- Opt-in login startup and higher CPU priority. Both are disabled by default, and priority can be returned to normal.
- An **experimental Ubuntu 20.04+ X11/Xorg client**, including in-memory capture, hold preview, highlight progress, configurable bindings, tray controls, and login startup.
- MIT license. Screenshots stay in memory and are cleared on exit.

### Download and run

On Windows x64, extract `hold-to-peek-2.0.0-win-x64.zip` and run `HoldToPeek.exe`; the .NET runtime is included. The Windows interface is in Simplified Chinese.

On Ubuntu, install `hold-to-peek_2.0.0_all.deb` using the apt command above, then launch `hold-to-peek`. The interface has bilingual labels. `SHA256SUMS.txt` covers both packages.

### Compatibility and validation

**Ubuntu requires X11/Xorg; Wayland is not supported, and real Ubuntu desktop/apt installation validation is pending.** During a peek, keyboard and pointer input is temporarily grabbed to isolate scrolling, then released. Linux may deny higher CPU priority; this is reported without requesting root access.

Windows build, 57 core checks, 9 settings groups, and 46 offline layout/runtime assertions passed. Linux passed 16 logic, simulated-input, Python 3.8 syntax, and package checks, plus static checks. Native desktop input, focus, DPI, lock/suspend, and multi-monitor behavior still need validation. The Windows executable is unsigned and retains the existing WFO0003 DPI build warning. README GIFs are interaction illustrations; some screens reflect version 1.0.0.
