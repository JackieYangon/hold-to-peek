# 瞄一眼 / Hold to Peek v1.0.0

按住看参考，松手接着干。适合一边照教程操作、一边填表或核对信息的单屏场景。

## 中文

### 这一版能做什么

- 框选一张参考截图，默认按住鼠标后退侧键查看，松开隐藏。
- 滚轮移动高亮线；Shift + 滚轮精调位置，再次查看保留阅读进度。
- 可选择鼠标前进侧键或 F8；设置中可看着当前参考试读行距。
- 托盘支持暂停、恢复、重新框选、清除参考和退出。
- 截图仅存内存，不上传、不自动落盘，退出后清除。

### 下载与使用

下载附件 **hold-to-peek-1.0.0-win-x64.zip**，解压后运行 **HoldToPeek.exe**。这是 Windows x64 免安装版，内置 .NET 10 运行时，无需另装 SDK。

首次打开时选好触发键，点击「框选参考」。关闭设置窗口后仍在托盘运行；彻底退出请右键托盘图标选择「退出」。

### 验证范围

构建、逻辑检查、离屏布局与打包完整性已检查。真实桌面侧键、焦点保持、不同 DPI、多屏及游戏兼容性仍需进一步验证；首轮目标是 Windows 11 x64 普通桌面应用。程序尚未代码签名。README 动图为带字幕的交互示意，非实机录屏。

## English

Hold to see your reference. Release to keep working. Built for following tutorials, filling forms, and checking information on a single screen.

### What's included

- Capture one reference image; hold the back mouse button to view it and release to hide it.
- Move the highlight with the wheel, fine-tune with Shift + wheel, and return to the same reading position.
- Choose the forward mouse button or F8 instead, and rehearse line spacing against the current reference in settings.
- Pause, resume, recapture, clear, or exit from the system tray.
- Screenshots stay in memory, are not uploaded or automatically written to disk, and are cleared on exit.

### Download and run

Download **hold-to-peek-1.0.0-win-x64.zip**, extract it, and run **HoldToPeek.exe**. This portable Windows x64 build includes the .NET 10 runtime; no SDK is required. The app interface is in Simplified Chinese.

Choose your trigger, then select “框选参考” (Capture reference). Closing settings leaves the app in the system tray. Right-click its icon and choose “退出” (Exit) to quit.

### Validation scope

Build, logic, offline layout, and package integrity checks passed. Physical side-button input, focus retention, DPI, multiple monitors, and game compatibility still need further desktop validation. The initial target is regular Windows 11 x64 desktop apps. The executable is not code-signed. README animations are captioned interaction illustrations, not desktop recordings.
