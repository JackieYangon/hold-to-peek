## 目标与范围

让用户在当前任务中临时查看参考，不用反复切换窗口。首版验证一个完整闭环：

**框选截图 → 回到工作窗口 → 按住显示 → 滚轮移动高亮 → 松开隐藏 → 再按恢复位置。**

首版只保留一张图、一条高亮线、一个可配置按住触发键，以及用于框选、暂停和退出的托盘入口。OCR、文字提取、多截图管理、云同步、自动更新和复杂编辑器不在首版范围内。

## 技术建议

当前采用 C# + WPF + Win32 互操作，目标为 .NET 10，SDK 已固定为 10.0.404。WPF 负责窗口、布局与绘制，Win32 负责全局输入和无焦点显示。构建、输入状态逻辑及离屏布局已通过检查，真实桌面交互仍需验收。[WPF 官方概述](https://learn.microsoft.com/en-us/dotnet/desktop/wpf/overview/)

| 职责 | 实现方向 |
| --- | --- |
| 框选截图 | 桌面取图与框选遮罩，统一物理像素和界面坐标；先支持单屏矩形区域 |
| 输入监听 | Win32 全局输入机制，识别触发键按下、松开及预览期间滚轮 |
| 临时预览 | WPF 无边框窗口，置顶但不激活，在鼠标附近定位并避让屏幕边缘 |
| 阅读进度 | 原图坐标中的高亮位置与可调行距，范围约束，同次运行内保留 |
| 生命周期 | 托盘、单实例、暂停和退出；异常时隐藏预览并释放监听和图像资源 |

Windows 的扩展窗口样式包含 `WS_EX_NOACTIVATE`；仍需在小样里检查显示、点击及键盘输入是否保留原应用焦点。[窗口样式文档](https://learn.microsoft.com/en-us/windows/win32/winmsg/extended-window-styles)

鼠标低级钩子可观察侧键和滚轮，处理后的事件可被截断；回调必须短小，耗时操作另行调度。钩子超时可能被系统静默移除，因此需要验证恢复与状态清理。[输入钩子文档](https://learn.microsoft.com/en-us/windows/win32/winmsg/lowlevelmouseproc)

## 首版交互细节建议

1. **创建参考**：从托盘开始框选，取消操作保留旧截图；完成新截图后替换旧图并重置高亮位置。
2. **按住触发**：预览出现在按下时鼠标的附近，本次显示期间不追随指针晃动；靠近屏幕边缘时换方向或限位。
3. **不抢工作焦点**：显示参考后，原来的表单、编辑器或设置窗口仍是活动窗口；预览避免遮挡鼠标当前操作点。
4. **滚轮标记**：预览可见时滚轮只改变高亮位置，底层窗口不跟着滚动；隐藏时滚轮恢复原行为。到达图片上下边缘后停止，不循环跳转。
5. **高亮含义**：采用可调整行距的高亮线，滚一格移动一个阅读单位。教程段落可能不等高，不承诺自动跳到语义上的下一步骤。
6. **松开与记忆**：松开立刻隐藏；本次运行内多次按住恢复高亮位置。退出后默认清除截图；设置可以保存，但不默认保存用户截图。
7. **触发冲突**：仅在工具启用且已有参考时接管所选侧键，并配对处理按下/松开，避免浏览器前进后退误触发。暂停或无图时保留原输入行为。
8. **输入异常**：快速按放、重复按下、锁屏、睡眠恢复和退出时都应恢复隐藏状态，避免卡住或持续吞滚轮；验证时保留托盘暂停/退出入口。

状态可以先简化为“无参考”“就绪且隐藏”“按住显示”“框选中”“暂停”。高亮进度属于参考内容，显示/隐藏不重置；成功替换截图才重置。

## 开发阶段与交付

以下是实现与验证顺序。源码实现不代表已经通过验收；阶段不会自动对应一次版本递增。

| 阶段 | 主要工作 | 可检查的结果 |
| --- | --- | --- |
| 0. 范围定义 | 明确首版体验、版本与开发计划 | 功能范围和验收标准清晰 |
| 1. 核心交互小样 | 固定图片、触发键按下/释放、无焦点预览、滚轮隔离 | 浏览器、记事本与 Windows 设置中按住显示、松开隐藏，原窗口保留焦点 |
| 2. 截图闭环 | 框选、取消、替换、显示定位、DPI 转换 | 截图清晰，取消保留旧图，屏幕四角不溢出工作区 |
| 3. 阅读进度 | 高亮线、初始位置与行距校准、滚轮边界、位置记忆 | 看完第二行后松开，再按仍是第二行，上下边界稳定 |
| 4. 首版交付 | 托盘、触发设置、暂停/退出、异常恢复、打包 | 无开发环境的目标机器能运行，完整完成对照教程操作任务 |

阶段 1 最先回答关键可行性问题：全局按住行为能否稳定工作，以及参考窗口会不会打断用户。通过后再投入框选和设置界面。

## 验收重点

首轮易用性改进包括：设置内用当前参考试读行距、首次使用的示例与可展开说明、从设置取消框选后返回、按 Esc 先收起触发键下拉菜单、再次打开设置时默认保存，以及托盘暂停状态和不可用操作反馈。试读不改变主阅读位置，仍只保留一张参考截图。

- 核心体验：一图一线一触发键的闭环完整，重复触发不卡住，无明显闪烁和焦点跳动。
- 输入正确：预览时滚轮不穿透到底层，隐藏/暂停时正常；所选侧键的按下/松开均妥善处理。
- 进度记忆：同一张图松开再按保留位置；换图重置；取消换图保留原图及进度。
- 显示正确：至少检查 100%、125%、150%、200% 缩放以及屏幕边缘；高亮基于原图坐标，不因缩放漂移。
- 生命周期：无图触发、截图取消、连续按放、暂停、锁屏/睡眠恢复、退出等状态不会留下悬浮窗或持续拦截输入。
- 资源与发布：空闲状态不做无必要的高频工作，退出释放钩子与图像；在目标环境验证发布包启动、版本显示及退出。
- 验收结论注明实际使用的系统、DPI 和输入设备，以及尚未验证的环境。

DPI 方案从一开始考虑每显示器缩放与坐标换算，首轮验收聚焦单屏；多屏跨屏框选另行评估。[DPI 官方文档](https://learn.microsoft.com/en-us/windows/win32/hidpi/dpi-awareness-context)

首版建议先验证 Windows 11 x64 上的普通桌面应用。管理员窗口、UAC 安全桌面、独占全屏或带保护机制的游戏，以及其他系统和架构，需要单独确认支持范围；不以提高权限作为默认解决方案。

## 后续可选方向

待首版体验证明有用后，再考虑人工设置不等距步骤锚点、跨重启恢复、多个参考、OCR 自动分行和更广泛兼容性。是否增加由实际使用反馈决定，并按已约定的版本规则发布。
