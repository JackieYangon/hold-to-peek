# 瞄一眼 · 使用说明

按住看参考，松手接着干。

## 框选与查看

1. 运行 `HoldToPeek.exe`，在「按键设置」确认快捷键，关闭设置后按 **F1** 快速框选。也可以点击「框选参考」或双击托盘图标。
2. 在鼠标所在屏幕拖出参考区域；Esc 或右键取消并保留旧图。
3. 回到工作窗口，按住默认鼠标后退侧键查看，松开隐藏；再次按住仍停在上次阅读位置。
4. 滚轮移动高亮；Shift + 滚轮精调。Esc 收起本次预览，松开触发键后可重新查看。

## 自定义设置

- **参考设置**：调节行距，用当前截图试读；没有截图时提供示例。试读不会改变主阅读进度。
- **按键设置**：点击按钮后按下新键，可搭配 Ctrl、Alt、Shift。查看还支持中键和前后侧键。两个动作需使用不同主键，Esc 取消录入；系统保留组合和 F12 不可用。
- **启动与运行**：可选登录后启动、CPU High 优先级，默认关闭。登录自启时留在托盘。移动程序目录后重新开关自启；优先级影响 CPU 调度，不是置顶设置。
- **使用说明**：随时查看操作和隐私说明。

点击「保存设置」生效，取消或关闭不保存。编辑设置时暂停接管快捷键；快捷键冲突会提示，仍可从托盘框选。

## 暂停与退出

右键托盘可暂停、恢复、清除参考、回到顶部或退出。关闭设置窗口后仍在托盘运行；再次打开程序会显示已有实例的设置。截图只存内存，退出即清除，不会随着自启恢复。只有偏好保存到 `%LOCALAPPDATA%\HoldToPeek\settings.json`。

Windows 普通桌面为目标环境，游戏、管理员窗口、多屏和混合 DPI 需要单独验证。当前程序未代码签名。
