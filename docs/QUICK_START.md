# 瞄一眼 · 首版使用说明

按住看参考，松手接着干。当前为本地首版，优先验证 Windows 11 x64 普通桌面环境。

## 打开与框选

1. 运行 `HoldToPeek.exe`，会看到设置与使用说明窗口；程序也会出现在系统托盘。
2. 选好触发键与行距，点击“框选参考”；在鼠标所在屏幕拖出需要参考的矩形区域。
3. 截图成功后切回正在操作的窗口。
4. 按住鼠标后退侧键查看参考，滚轮向下移动高亮，松开隐藏。再次按住保留阅读位置。

如果鼠标没有侧键，在设置中改用 `F8`。也可以选择鼠标前进侧键。同一时刻只有一个触发键。

## 调整与退出

- 行距按原图像素计算。在设置中拖动滑块，可以直接看到当前参考的高亮变化；点击“上一行 / 下一行”或在试读图上滚轮检查效果。试读不改变原来的阅读位置，没有截图时会提供示例。
- 修改设置后点击“保存设置”生效；关闭或取消不保存修改。首次使用时 Enter 默认开始框选；之后 Enter 默认保存设置，重新截图需点击“框选参考”。
- 查看参考时按住 `Shift` 再滚轮，每格微调 1 个原图像素，方便把高亮对准第一行。
- 长截图会在预览内部随高亮位置滚动。高亮线标记阅读位置，不自动识别教程步骤。
- 框选时按 `Esc` 或鼠标右键取消，原截图和阅读位置保留。从设置发起框选时，取消会回到设置；选区太小时可直接重新拖选。
- 按住查看时按 `Esc` 立即收起；松开触发键再按即可重新查看。
- 双击托盘图标重新框选；右键托盘可设置、暂停、回到顶部、清除截图或退出。
- 暂停或没有截图时，鼠标侧键与 F8 保持原来的作用。工具启用且有截图时，所选触发键由瞄一眼接管。

关闭设置窗口后程序仍在托盘运行，需用托盘“退出”彻底关闭。再次启动程序会打开已有实例的设置窗口。

## 本地资料

截图只保存在本次进程内存中，不上传、不自动落盘，退出后清除。只有触发键和行距等偏好保存到 `%LOCALAPPDATA%\HoldToPeek\settings.json`。

首版尚未全面验证 Windows 10、ARM64、多显示器混合缩放、管理员程序和游戏场景。UAC 安全桌面、受保护内容及独占全屏游戏不在当前支持承诺内。
